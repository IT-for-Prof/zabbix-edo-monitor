# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/): patch — правки описаний и макросов по умолчанию, minor — новые элементы, триггеры, теги, major — смена ключей или формата записей целей.

## [1.3.0] — 2026-09-17

Первая публичная версия.

### Проба `edo.ps1`
- Цепочка DNS → TCP → TLS → HTTP до цели с классом отказа на первом сломанном шаге; режимы `http`, `stall` (POST 256 КБ по TLS 1.2) и `gost` (`csptest -tlsc -hello -exchange 3`).
- Один JSON-объект в stdout и код выхода 0 при любом исходе, ничего в stderr; бюджеты фаз с общим сроком 25 с.
- Строгая проверка аргументов: неверная запись даёт класс 91, а не отказ агента.

### Шаблон Zabbix 7.0
- Цели из макросов `{$EDO.TARGETS.*}` через обнаружение без запуска PowerShell; макросы подаёт шаг «Регулярное выражение», а не JavaScript ([ZBX-25568](https://support.zabbix.com/browse/ZBX-25568)).
- Сводки хоста и цепочка зависимостей: доступность агента → «проба не работает на хосте» → «массовый отказ с хоста» → триггеры целей. Отказ, общий для хоста, — одна проблема.
- Триггеры цели: «недоступен» (High), «нет данных пробы», «проверка невозможна» (Average), «нестабилен», «медленный ответ», «сертификат истекает» (Warning). Выражения восстановления не дают закрыть проблему посреди отказа.
- Триггер версии скрипта по MD5, теги `class`/`target`/`vendor`, `component`, `endpoint`/`mode`/`service`, `scope`.

### Тесты
- Pester под Windows PowerShell 5.1: классы пробы на локальных фейковых серверах; согласованность шаблона, пробы, конфига агента и README, включая разбор целей JavaScript обнаружения.
